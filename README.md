## Проверка ввода

Все значения вводятся через функцию `ReadValue`. Она читает всю строку, которую ввел пользователь, и принимает ее, только если в строке одно значение нужного типа и оно входит в допустимый диапазон. Если это не так, программа пишет, какой диапазон допустим, и просит ввести значение заново.

### Текст задачи

Дана сигнатура функции: int numLen (long x);
